## 3. 对照验收（design D5）

> 并发跑（20 条 @5）观察到三项异常需对照定性：工具 F1 21.5%、序列正确率 0%、任务成功率 0/18
> （全量 41 条基线为 54.4% / 46.3% / 20.8%）；槽位完整率 100%(n=8) 正常，说明工具确有触发。
> 子集与全量不可比，故必须以同子集串行跑作对照。

- [x] 3.1 同子集（前 20 条）对照实测：并发5 F1 21.5%/召回 15.0%/序列 0%/任务 0/18/槽位 100%(n=8)；串行1 F1 14.0%/召回 10.0%/序列 0%/任务 0/18/槽位 100%(n=6)
- [x] 3.2 判定**无并发污染**：序列/任务成功率两项在串行侧同样为 0（子集特性非并发缺陷）；槽位两侧均 100%；F1 差 +7.5pp 但**方向为并发更优**（污染只会劣化），且 ±5.7pp 是 3 采样均值的半宽、单次跑离散度约 √3 倍。最终定论以全量 3 采样基线跑复核（见 4.1）
- [x] 3.3 实测提速比：20 条子集 并发5 **161s** vs 串行 **725s** → **4.5×**；全量 41 条×3 采样 **1105s(18.4min)** vs 串行约 57min → **3.1×**（全量含 8 条多轮长尾，故低于子集）
- [x] 3.4 全量 3 采样终审（并发 vs 串行基线）：F1 56.2%±12.0 vs 54.4%±5.7（+1.8pp）、槽位 87.7%±5.3 vs 79.6%±28.7（+8.1pp）、序列 48.0% vs 46.3%、任务成功率 23.6% vs 20.8%、参数级 11.1% 持平；**全部在实测半宽内且方向持平或略优，0 条真跑失败 → 判定无并发污染**
